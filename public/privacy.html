Private Hub privacy notice

Private Hub is a personal, single-owner application. Access is protected by passwordless authentication and database row-level security.

Data used

The application stores account records, document metadata, notes, memberships and, when explicitly connected, read-only bank account balances and transactions. Uploaded documents are held in a private storage bucket. Banking credentials are never requested or stored by Private Hub.

Service providers

Supabase provides authentication, database, storage and server-side functions. Enable Banking processes account-information consent and read-only banking data when connected. GitHub Pages hosts the public application files.

Control and retention

The owner can disconnect banking access and delete stored personal content. Existing historical data is retained after a temporary bank outage or consent expiry so that it is not lost accidentally.
